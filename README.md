# Shivaraj Gandham — Portfolio

A Next.js (JavaScript) portfolio with an animated 3D knowledge-graph hero, Framer Motion scroll animations, and sections for skills, experience, flagship enterprise builds, live deployments, and a filterable grid of 25+ GitHub repos.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy

Push to GitHub and import into Vercel (recommended for Next.js), or run:

```bash
npm run build
npm start
```

## Stack
- Next.js 14 (Pages Router, JavaScript)
- Tailwind CSS
- Framer Motion (scroll & entrance animations)
- @react-three/fiber + three.js (3D hero visualization)
- react-icons

## Editing content
All project/skill/experience data lives in `data/projects.js` and the individual components in `components/`. Update your live links, GitHub repos, or resume details there.
